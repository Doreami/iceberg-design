# Puffin文件格式 - 说明

Puffin 是 Apache Iceberg 的配套统计与索引文件格式，用于存储无法放入 Manifest 中的辅助信息。Puffin 管理优化元数据，忽略 Puffin 不会影响查询结果正确性，可扩展（通过 type 字符串标识 Blob 类型）。



## 文件格式

```textile
┌─────────────────────────────┐
│  Magic (4 bytes)   "PFA1"   │
├─────────────────────────────┤
│  Blob₁                      │
│  原始索引/统计二进制数据        │
│  (变长,可压缩)                │
│                             │
├─────────────────────────────┤
│  ...                        │
├─────────────────────────────┤
│  Blobn                      │
│  原始索引/统计二进制数据        │
│  (变长,可压缩)                │
│                             │
├─────────────────────────────┤
│  Magic (4 bytes)   "PFA1"   │
├─────────────────────────────┤
│  FooterPayload   (变长)      │
│  UTF-8 JSON, 可选 LZ4 压缩    │
│ Json分两部分：                │
│ 1. blob metadata            │
│ 2. 文件级自定义properties     │
├─────────────────────────────┤
│  FooterPayloadSize          │
│  (4 bytes)                  │
├─────────────────────────────┤
│  Flags (4 bytes) 压缩标志    │
├─────────────────────────────┤
│  Magic (4 bytes)   "PFA1"   │
└─────────────────────────────┘
```

- **Magic**：固定值PFA1，快速文件类型识别

- **blob区域**：各索引自己实现的二进制数据

- **FooterPayload**：Json格式数据
  
  - **blob metadata**：数组，每个blob的元信息，参考下表**BlobMetadata 字段**
  
  - **properties**：自定义KV配置



**BlobMetadata 字段**

| 字段                  | JSON 类型 | 必需  | 说明                          |
| ------------------- | ------- | --- | --------------------------- |
| `type`              | string  | ✅   | Blob 类型标识符                  |
| `fields`            | int[]   | ✅   | Iceberg 字段 ID 列表            |
| `snapshot-id`       | long    | ✅   | 源快照 ID                      |
| `sequence-number`   | long    | ✅   | 源快照序列号                      |
| `offset`            | long    | ✅   | Blob 数据在文件中的起始字节偏移          |
| `length`            | long    | ✅   | Blob 数据字节长度（压缩后）            |
| `compression-codec` | string  | ❌   | `"lz4"` / `"zstd"`；省略 = 不压缩 |
| `properties`        | map     | ❌   | 任意 key-value 元数据            |



## puffin footer json示例：

```json
{
 "blobs": [
     {
         // 类型, 命名格式一般为<org>.<project>-<index-type>-v<version>
         "type": "apache-datasketches-theta-v1",
         "fields": [1, 2], // 索引字段id数组
         "snapshot-id": 8027658604211071520, // 源snapshot-id
         "sequence-number": 1, // 源sequence-number
         "offset": 4, // blob区域对应文件的offset
         "length": 4096, // blob区域size
         "compression-codec": "zstd", // blob区域压缩算法
         "properties": { // blob级自定义properties
             "ndv": "1000000"
         }
     }
 ],
 "properties": { // 文件级自定义properties
     "writer-version": "iceberg-cpp/1.0.0",
     "created-by": "index-builder"
 }
}
```





## Metadata.json

在定义中，metadata.json中提供字段`statistics`用来存储puffin的相关信息

```json
"statistics": [
  {
    "snapshot-id": 8027658604211071520,
    "statistics-path": "s3://bucket/warehouse/db/orders/metadata/snap-8027658604211071520-1-def.puffin",
    "file-size-in-bytes": 13107200,
    "file-footer-size-in-bytes": 2048,
    "blob-metadata": [
      {
        "type": "apache-datasketches-theta-v1",
        "source-snapshot-id": 8027658604211071520,
        "source-snapshot-sequence-number": 1,
        "fields": [1, 2],
        "properties": {
          "ndv": "48000000"
        }
      },
    ]
  }
]

```



`snapshot-id`：snapshot id

`statistics-path`：puffin文件路径

`file-size-in-bytes`：puffin文件大小

`file-footer-size-in-bytes`：puffin Footer大小

`blob-metadata`：blob元信息，基本与puffin实际存储的内容一致。对比puffin文件没有offset、length、 compression-codec字段，properties字段里可以仅存储部分内容需求的内容。

<mark>是否需要维护metadata.json的`statistics`字段，还是由GV维护（GV描述这张表对应的snapshot下，有哪些索引文件）</mark>

# 核心数据结构

```c
/* ==================== 压缩 Codec 枚举 ==================== */

typedef enum {
    PUFFIN_COMPRESSION_NONE = 0,
    PUFFIN_COMPRESSION_LZ4  = 1,
    PUFFIN_COMPRESSION_ZSTD = 2,
} puffin_compression_t;

/* ==================== Key-Value 属性对 ==================== */

typedef struct {
    char   *key;        /* 属性键 */
    char   *value;      /* 属性值 */
} puffin_kv_t;

/* ==================== Blob 元数据 ==================== */

typedef struct {
    char                 *type;            /* Blob 类型标识符 (malloc'd) */
    int32_t              *fields;          /* 关联字段 ID 数组 (malloc'd) */
    size_t                fields_count;    /* 字段 ID 数量 */
    int64_t               snapshot_id;     /* 源快照 ID */
    int64_t               sequence_number; /* 源快照序列号 */
    int64_t               offset;          /* 文件内字节偏移 */
    int64_t               length;          /* 字节长度 (压缩后) */
    puffin_compression_t  compression;     /* 压缩方式 */
    puffin_kv_t          *properties;      /* 自定义属性数组 (malloc'd) */
    size_t                properties_count;/* 属性数量 */
} puffin_blob_metadata_t;

/* ==================== 文件元数据 ==================== */

typedef struct {
    int                     footer_version;    /* Footer 版本, 当前为 1 */
    puffin_blob_metadata_t *blobs;            /* Blob 元数据数组 */
    size_t                  blob_count;       /* Blob 数量 */
    puffin_kv_t            *properties;       /* 文件级属性数组 */
    size_t                  properties_count; /* 文件属性数量 */
    int64_t                 footer_offset;    /* Footer 在文件中的起始偏移 */
} puffin_file_metadata_t;

/* ==================== Footer 读取结果 ==================== */

typedef struct {
    puffin_file_metadata_t  metadata;          /* 解析后的元数据 */
    size_t                  footer_payload_size; /* Footer 负载大小 */
    uint32_t                flags;             /* Footer flags */
} puffin_footer_result_t;

/* ==================== Blob 完整读取结果 ==================== */

typedef struct {
    puffin_blob_metadata_t  metadata;  /* Blob 元数据 */
    uint8_t                *data;      /* 已解压的 Blob 数据 (malloc'd) */
    size_t                  data_len;  /* 解压后数据长度 */
} puffin_blob_t;
```
